# HW2

Assignment #2 of Intro to Software Engineering (Tel Aviv University, 2027A).
The full instructions are in the assignment document on Moodle.

| Path | What is it |
| --- | --- |
| `src/il/ac/tau/cs/software1/bigram/` | Part A: the bigram language model (file I/O) |
| `src/il/ac/tau/cs/software1/` (all the other packages) | Part B: the Pacman game. You work in `inventory/` and `pacman/` |
| `resources/` | Input files for Part A, and the scene and textures of the game |
| `test/` | JUnit sanity tests. Do not change them |
| `.github/workflows/tests.yml` | Runs the tests on GitHub after every push. Do not change it |
| `details.txt` | Your TAU username goes here |
